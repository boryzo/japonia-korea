
## Deployment Rule
After making any code changes in this project, ALWAYS automatically commit and push the changes to GitHub (e.g. `git add . && git commit -m '...' && git push`). This will trigger the GitHub Pages deployment automatically.

## Universal AI Context Rule
There is a file called `AI_CONTEXT.md` in the root directory. It serves as a universal prompt and documentation for any AI model working on this project. Whenever you make significant structural, architectural, or logic changes to this application, you MUST explicitly update `AI_CONTEXT.md` to reflect these new patterns.
